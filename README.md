# Gemini 3.8 TTS（網頁版 + 本機版）

同一套介面，兩種用法：

| | 網頁版（GitHub Pages / Android PWA） | 本機版（Windows，`啟動圖形介面.bat`） |
|---|---|---|
| 介面 | 瀏覽器、可安裝到手機主畫面 | Chrome（優先）或 Edge 的應用程式視窗（可改，同一套介面） |
| ffmpeg | ffmpeg.wasm（首次下載約 31 MB） | 電腦上的原生 ffmpeg（可一鍵安裝） |
| 儲存 | 下載 / 分享到其他 App | 自動存入輸出資料夾 + 最近生成清單 |
| API Key | 使用者自己輸入，存在瀏覽器 | 輸入或環境變數 `GEMINI_API_KEY`，可存成本機檔案 |
| 呼叫 Gemini | 瀏覽器直接呼叫 | 經本機服務轉送（無瀏覽器跨來源問題） |
| 設置 | 瀏覽器內 | `local/tts_settings.json`（與命令列版共用） |

## 專案結構

```
site/        網頁版（部署到 GitHub Pages）
local/       本機版：tts_gui.py（圖形介面）、tts.py（命令列）
.github/     自動部署流程（部署時下載固定版本 ffmpeg.wasm）
deploy.py    一鍵推送工具（見 SOP.md）
一鍵推送.bat  啟動圖形介面.bat  啟動命令列.bat
```

**更新與推送流程請看 [SOP.md](SOP.md)。**

## 功能（兩種版本共通）

- 人聲：直接輸入名稱／ID、線上清單（可篩選、翻頁）、內建 30 種；每個都能 ▶ 試聽（用你目前的文本開頭與語氣）。
- 單人旁白、多人對話（`名稱[語氣]: 內容`，超過 2 位或自訂人聲自動逐段合成）、語氣控制、長文自動分段。
- 輸出：wav / pcm / mulaw / alaw / mp3 / flac / ogg / opus / m4a；取樣率、位元率、響度標準化、變速、保留原始 WAV。
- **批次模式**：文本以單獨一行 `---` 分隔，每段各產生一個檔案。
- Ctrl + Enter 直接生成、設置自動沿用、匯出/匯入設置、失敗自動重試、轉檔失敗保留原始 WAV。

## 音色克隆（Voice replication）

人聲選單 →「我的克隆」→「建立新的克隆聲音」：

1. 選同意聲明語言（官方 30 種；中文只有簡體 `zh-CN`，請以國語朗讀該句原文）。
2. 錄製或上傳 **10–30 秒**參考音訊（超過 30 秒自動取前 30 秒）。
3. 錄製或上傳**同意錄音**（朗讀畫面上的聲明原文），兩段請用同一支麥克風、同一個安靜環境。
4. 取名、選儲存方式、勾選「這是我本人的聲音／已取得本人同意」。

- **儲存在 Google 專案**（`voice_…`）：保留 1 年，每專案上限 200 個。
- **不儲存**（`voicekey_…`）：Google 不留存聲紋；金鑰 7 天有效，只存在你的裝置（網頁版：瀏覽器；本機版：`local/tts_voices.json`）。
- 只能複製你本人或已明確同意的成年人的聲音；Google 會驗證兩段錄音是否為同一人。

## 本機版安全設計

服務只綁定 `127.0.0.1`，驗證 Host 標頭與隨機 token，拒絕跨來源請求；Gemini 轉送只開放 `/interactions` 與 `/voices`；
ffmpeg 參數採白名單（只接受介面會產生的值），檔案存取限制在輸出資料夾內。

## 注意事項

- 金鑰與克隆金鑰屬機密：`local/` 內的設置、金鑰、輸出已列入 `.gitignore`，且推送前會自動掃描。
- 網頁版建議在 Google AI Studio 為金鑰設定用量／預算上限。
- 生成過程中請讓頁面留在前景（網頁版會嘗試保持螢幕常亮）。
