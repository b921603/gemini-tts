Gemini TTS

1. API Key

金鑰只會從你的瀏覽器直接送到 Google，不經過其他伺服器。 取得金鑰　

2. 文本

每行一句：名稱: 內容，或 名稱[語氣]: 內容 指定該句語氣。沒有「名稱:」開頭的行會接在上一句後面。

3. 人聲與語氣

想用自己的聲音？點上方人聲 → 「我的克隆」即可建立。

整段的情緒／語速寫在「語氣」；單一時間點的 <laugh> <sigh> <short pause> 直接寫進文本（標籤用英文）。

            建立克隆聲音

            ③ 同意錄音 （朗讀上方聲明原文）
            
  
            
  
            兩段請用同一支麥克風、同一個安靜環境錄製（避免回音、背景音樂與他人說話聲），驗證較容易通過。
